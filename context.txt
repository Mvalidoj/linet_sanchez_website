# 1. IDENTIDAD

Linet Sánchez — visual artist portfolio (fotografía, escultura, video).
Sitio web editorial 100% estático, en inglés, para audiencia profesional del
arte (instituciones, curadores, galerías, coleccionistas, prensa).

Debe sentirse como una exposición curada o un libro de artista: la obra como
protagonista a escala natural, la interfaz retirándose ante ella, el espacio
vacío como material de diseño. NO: portfolio genérico, web corporativa,
landing comercial o plantilla.

# 2. DECISIONES RATIFICADAS (2026-11-17)

1. **Stack:** Astro 7 + TypeScript (strict) + Tailwind CSS v4 (CSS-first).
   Sitio estático puro, **sin CMS** (Sanity eliminado). Despliegue:
   Cloudflare Pages + GitHub. (ADR-004)
2. **Dirección visual:** estructura de pinomusi.com ratificada; la spec
   "THE ARCHITECTURE OF MEMORY" (Cormorant Garamond + Inter, Warm Paper)
   queda desechada. Tipografía: solo Arial, sin webfonts. (ADR-005)
3. **Arquitectura:** clean architecture adaptada a Astro — domain (Astro-free)
   / data (única capa con getCollection) / content collections JSON con zod
   / presentación fina. Sin DI ni repos. (ADR-006)
4. **Imágenes de obra:** servidas byte a byte, sin procesamiento (nunca
   recortar/recolorear: `object-fit: contain` prohibido usar `cover`). (ADR-007)
5. **context.txt:** reescrito por consenso como brief vigente. (ADR-008)

# 4. REGLAS OPERATIVAS (resumen; el detalle está en CLAUDE.md)

- Leer CLAUDE.md y la documentación del task antes de tocar código.
- La bíblia de diseño (docs/design/) manda; pinomusi/ es material de archivo,
  no se consulta para decidir y nunca se copia su contenido editorial.
- No inventar contenido del artista (títulos, fechas, exposiciones...);
  alt text siempre presente y provisional si la obra no está identificada.
- Contenido = JSON en src/content/ (content collections); cambios = commits.
- Invariantes de arquitectura verificables con grep (ver CLAUDE.md §4b).
- Aprobación explícita del usuario para pasar de fase.
